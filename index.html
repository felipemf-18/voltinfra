Integration & Quickstart

curl -X POST "https://api.voltinfra.xyz/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $VOLT_API_KEY" \
  -d '{
    "model": "qwen/qwen2.5-8b",
    "messages": [
      { "role": "system", "content": "You are a concise systems engineer." },
      { "role": "user", "content": "Return benchmark parameters in JSON." }
    ],
    "temperature": 0.2,
    "max_tokens": 512,
    "stream": true
  }'
from openai import OpenAI

client = OpenAI(
    base_url="https://api.voltinfra.xyz/v1",
    api_key="sk-volt-..."
)

stream = client.chat.completions.create(
    model="qwen/qwen2.5-8b",
    messages=[
        {"role": "user", "content": "Ping inference endpoint"}
    ],
    temperature=0.2,
    max_tokens=512,
    stream=True
)

for chunk in stream:
    token = chunk.choices[0].delta.content
    if token:
        print(token, end="", flush=True)

Data Privacy & Sovereignty

Zero Data Retention (ZDR) Policy

All requests are processed in ephemeral memory. Prompts and completions are never logged, cached to disk, or retained for model training under any circumstances.

Ephemeral RAM/VRAM
KV cache and token activations exist solely in volatile memory and are purged immediately post-stream.
Zero Disk Storage
Inference containers run with payload logging strictly disabled. No input/output data is persisted to disks.
No Training or Tuning
Payloads are never pooled, mined, or used for model training, reinforcement learning, or evaluation.
